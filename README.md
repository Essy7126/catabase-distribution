# Catabase — versions de test

Un roguelite tactique au tour par tour dans les Enfers.

## Jouer sur Windows

1. [Télécharger CatabaseLauncher.exe](https://github.com/Essy7126/catabase-distribution/releases/latest/download/CatabaseLauncher.exe).
2. Ouvrir le launcher et cliquer sur **Installer le jeu**.
3. Cliquer sur **Jouer**.

Le launcher affiche les actualités, propose les mises à jour et conserve la
version installée en cas d’échec. Le jeu est aussi jouable hors ligne après
installation. Les sauvegardes du jeu sont séparées de l’installation.

Ce dépôt contient les versions jouables et les actualités. Le code source du
jeu est conservé dans un dépôt distinct. [Historique des versions](https://github.com/Essy7126/catabase-distribution/releases).
